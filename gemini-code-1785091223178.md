# Product Requirement Document: Distraction-Free Single-Task Focus & Parking Lot App

## 1. Project Goal
Build a minimalist web application designed to reduce anxiety during deep work sessions by enforcing "selective sight." The app isolates a single task from the user's backlog and provides a frictionless "Parking Lot" input to capture intrusive thoughts without breaking focus.

## 2. Multi-User & Authentication
- **Authentication Method:** Google Account Sign-In via Google OAuth (Firebase Auth or Supabase Auth).
- **Data Scoping & Security:** Strict user isolation. All tasks, session logs, and parking lot items MUST be scoped to the authenticated user's `userId`. User A (e.g., Husband) and User B (e.g., Wife) must have completely separate environments and data stores.
- **Public/Protected Routes:** Unauthenticated users see a sleek login page with "Sign in with Google". Redirect to the main app dashboard upon login.

## 3. Key UX Views & Core Features

### View A: Planning Mode (Backlog & Queue)
- **Brain Dump Input:** Quick textarea/input to add multiple tasks into the backlog.
- **Queue Reordering:** Simple drag-and-drop or arrow controls to prioritize tasks.
- **Start Focus Action:** A prominent "Start Focus Session" button that locks the app into Focus Mode with the top task.

### View B: Focus Mode ("Selective Sight")
- **Task Isolation UI:** The backlog MUST be completely hidden. Show only:
  1. The single active task title and description.
  2. A customizable session timer (e.g., 25-minute Pomodoro style with play/pause/reset).
  3. Action buttons: "Mark Done" (archives task, loads next in queue), "Defer to End" (pushes to back of queue), and "Exit Session".
- **Global Parking Lot Hotkey (`Cmd+K` or `Ctrl+K`):** 
  - Pressing the hotkey instantly highlights a minimalist input box: *"Park a thought..."*
  - Typing a thought and hitting `Enter` saves the note directly to the user's `Parking Lot` list and clears the input—without pausing or interrupting the active focus timer.
  
### View C: Parking Lot Drawer
- A collapsible side tray or bottom drawer accessible in both Planning and Focus modes.
- Displays all parked thoughts captured during sessions.
- Actions per parked item: "Convert to Backlog Task" or "Dismiss/Clear".

## 4. Recommended Stack
- **Frontend:** React (Vite or Next.js) + Tailwind CSS + Lucide React Icons.
- **Backend / DB / Auth:** Firebase (Cloud Firestore + Firebase Auth) OR Supabase (PostgreSQL + Supabase Auth).
- **State Management:** Zustand or React Context for managing active session state and hotkey listeners.

## 5. Data Schema

### `users` Table / Collection
- `uid`: string (Primary Key)
- `email`: string
- `displayName`: string
- `photoURL`: string

### `tasks` Table / Collection
- `id`: string
- `userId`: string (Foreign Key -> users.uid)
- `title`: string
- `status`: 'backlog' | 'active' | 'completed'
- `position`: number
- `createdAt`: timestamp

### `parking_lot` Table / Collection
- `id`: string
- `userId`: string (Foreign Key -> users.uid)
- `note`: string
- `processed`: boolean
- `createdAt`: timestamp

## 6. Antigravity Verification & Acceptance Criteria
1. Verify Google Sign-In workflow renders and handles user authentication successfully.
2. Confirm that logging in as User A shows a different backlog than User B.
3. Test that entering Focus Mode hides the rest of the queue.
4. Test pressing `Cmd+K` / `Ctrl+K` while the focus timer is running, type a note, press `Enter`, and verify it appears in the Parking Lot drawer without resetting the timer.
5. Provide a full setup guide in the README detailing how to add Google OAuth credentials (`CLIENT_ID` / Firebase config).
